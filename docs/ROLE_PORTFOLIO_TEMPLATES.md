# Role-specific React portfolios

These presets extend the original five visual templates. Each pairs hiring-relevant evidence with an accessible, local interactive demo.

- [Backend Engineer / System Architecture](roles/backend/README.md) — A blueprint-led systems portfolio pairing throughput evidence with an interactive API contract inspector.
- [Cybersecurity / Threat Intel & Audit](roles/security/README.md) — A tactical research portfolio with searchable findings, explicit remediation evidence, and an accessible disclosure drawer.

Shared contracts validate all inputs. Native buttons, labeled controls, unique React IDs, visible focus, semantic main/section landmarks, and container-based reflow support keyboard and narrow-screen use. Sample profiles, research, and metrics are labeled as illustrative; the demos do not perform network requests or execute displayed code.

Implementation references: [React useId](https://react.dev/reference/react/useId), [Tailwind source detection](https://v3.tailwindcss.com/docs/content-configuration), and [WAI modal-dialog behavior](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/). Generated portfolios build independently with React 18, TypeScript, Tailwind, and Vite.
